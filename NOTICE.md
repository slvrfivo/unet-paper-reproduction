# Dataset and benchmark notice

This repository contains code, notebook experiments, and visualizations; it does **not** redistribute CamVid or ISBI raw datasets or trained model checkpoints. The notebooks download public mirrors at run time. Please follow each dataset's original usage and attribution terms.

ISBI metrics use six held-out slices from the public training volume, **not** official ISBI test-set scores. The notebooks are a learning-focused reproduction rather than a claim to reproduce the original benchmark.
